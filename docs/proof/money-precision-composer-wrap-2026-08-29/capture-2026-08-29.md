# Visual proof: money reads in cents, composer toolbar wraps at 375px

Pull request #1376. Captured 2026-08-29 against a chat front end built from
this branch, not from `main`.

## What was running

The image is `hive-owui:fixmoney-1349`, built from this worktree with
`docker build -f deploy/docker/Dockerfile.open-webui`, so the bundle under
test is the one this branch produces, including
`vendor/open-webui/src/lib/hive/credits.ts` and
`vendor/open-webui/src/lib/components/chat/MessageInput.svelte`. It ran
standalone on `http://localhost:3399` with `WEBUI_AUTH=false` and a local
SQLite database. No credential appears in any URL captured here, and no
Hive deployment, account or database was touched.

One upstream response is mocked, and only one: Playwright fulfils
`**/api/v1/hive/credits/**` with

```json
{"available_credits": 858, "usage_today_credits": 858, "top_up_url": ""}
```

858 credits is the exact balance that rendered `$0.000000858` on the deployed
box. Every string in the screenshots is produced by this build's own
formatter from that JSON; nothing about the formatting or the layout is
mocked.

## Composer geometry at 375px

Bounding boxes read from the live DOM at a 375 by 812 viewport, with the same
measurement the design review used.

Before, on the deployed box at SHA 37d49fcf8:

```
Cowork      x124-199
Hive Auto   x145-272
```

Both on one row, fifty-four pixels of overlap, the two labels printing on top
of each other.

After, on this build, in Chat mode and again in Cowork mode:

```
BOXES BEFORE COWORK: {"Chat":"x67-122 y401-429","Cowork":"x124-199 y401-429","modelChip":"x25-145 y441-469 text=Select a model"}
BOXES AFTER COWORK:  {"Chat":"x67-122 y383-411","Cowork":"x124-199 y383-411","modelChip":"x25-145 y423-451 text=Select a model"}
```

The mode toggle occupies y401-429 and the model chip y441-469: different
rows, so the horizontal ranges cannot overlap at all. Selecting Cowork moves
both rows up by 18 pixels to make room for the Cowork row underneath, and the
separation is unchanged.

The chip reads "Select a model" rather than "Hive Auto" because this
standalone instance has no model catalogue configured. It is 120 pixels wide
against the deployed chip's 127, and the two are on separate lines either
way, so the wider label cannot reintroduce the overlap.

## Console side

The same formatter change on the Next.js console is covered by its own suite
rather than by a screenshot: `docker compose run --build web-console npm run
test:unit` passes 903 tests, including `credit-balance.test.tsx`, which
renders the real `CreditBalance` card and asserts the reserved figure now
reads the sub-cent bound. `npm run build` is green.
