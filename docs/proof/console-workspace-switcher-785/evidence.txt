Issue #785 proof: console sidebar workspace switcher

Substrate: the real ConsoleShell / WorkspaceSwitcher component tree, run via
`next dev` inside the project's own web-console Docker image (same image the
build/test steps use), hit with a real Chromium browser (Playwright). This is
NOT the hosted demo box (console-hive.scubed.co) -- this sandbox has no live
Supabase credentials, so a throwaway, unauthenticated route rendered the same
production ConsoleShell with two demo prop sets (one 2-membership account, one
1-membership account) and no getViewer()/control-plane call. The route was
deleted before committing; it is not part of the shipped diff. No live
credential, session, or real workspace data was used or is visible in any
image -- account names ("Hive Demo", "Acme Legal Workspace") and the user
("Demo Owner" / owner@example.com) are fabricated placeholders. There is no
address bar in a component-level screenshot, so no URL redaction applies.
