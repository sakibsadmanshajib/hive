# Visual proof: the chat credit banner rounds a balance down (issue #1345)

Captured 2026-08-29 against a locally running chat stack built from this
branch. The image under test is `hive-owui:agent1345`, a private tag built
from this worktree with `docker build -f deploy/docker/Dockerfile.open-webui`,
so the bundle in the browser is the one this branch produces and not a
previously built tag.

## Stack

- `hive-owui:agent1345`, the full chat image from this branch. Its frontend
  stage builds `vendor/open-webui`, which is where the changed module lives,
  and its backend carries the usual `deploy/docker/owui-patches` including
  `hive_credits.py`, the shim the banner calls.
- A four line HTTP stub standing in for control-plane on the same Docker
  network, answering `POST /internal/chat/credits/balance` with a fixed
  payload. Only the source of the number is stubbed. The shim, the session
  check, the frontend fetch and every line of formatting are the real ones
  from this image.
- A local Open WebUI account created through the product's own signup route,
  signed in through the product's own form. No shared fixture account was
  touched and no password was reset anywhere.

## What the banner rendered

```
GET /api/v1/hive/credits/balance   -> 200 (both captures)

available_credits 9,996,364,207    -> "You've used $0.34 today - $9.99 remaining"
available_credits   499,999,999    -> "You've used $0.34 today - $0.499 remaining", amber low pill
```

The first case is the defect from the issue. 9,996,364,207 credits is
$9.996364207, and the price formatter this banner used to call rendered it as
ten dollars flat, which is more money than the account holds. The built bundle
now prints $9.99. Nothing but the floor path can produce that string from that
number, so this capture is also the check that the change reached the built
artifact rather than only the working tree.

The second case is the boundary. 499,999,999 credits is one credit under
`LOW_CREDITS_THRESHOLD`, and `creditState` calls it low. It used to render as
the threshold figure itself, so the pill said low while the number said the
account was at the threshold. It now renders $0.499 beside the amber pill, so
the two agree.

## Credentials

No credential appears in either URL. Sign in went through the form, so no
token rode in a query string, and there is nothing to redact in the text or in
the pixels. The account is local to a throwaway container that was removed
after the capture.
