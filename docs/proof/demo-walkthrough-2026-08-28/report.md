## Ranked findings (see report-walkharness.md for the owner-facing ranking and full detail)

1. "Hive Auto" alias returns a raw upstream quota-exceeded error verbatim to the chat UI, reproduced twice.
2. Chat sign-in's OAuth round trip is slow (15-20s) and shows an unbranded "Checking your authorization request..." interstitial; a fix (PR #1083, silent SSO consent) is already in flight.
3. The live Cowork composer does not match the vendored `AgentTasks.svelte` source (`#hive-agent-instructions`/`#hive-agent-send` are not what's mounted); it reuses `#chat-input`. Either dead code in the vendored tree or a routing gap worth a source-audit.
4. The pre-D-045 separate-auth `/agent-workspace/tasks` route is still live and reachable, rendering the exact "separate sign-in, doesn't look like chat" pattern the owner explicitly rejected on 2026-08-23.
5. Console dashboard's "Available credits" renders a raw unlabelled 9-digit integer with no currency/unit marker (credit-unit-v2 is 1e9 per USD, D-046).
6. D-045 says "Knowledge" is eliminated, replaced by Projects + Artifacts; the live sidebar still renders both "Projects" and "Knowledge" nav items (confirmed via raw DOM capture, `id="hive-nav-knowledge" href="/knowledge"` present alongside `id="hive-nav-projects" href="/projects"`). Related but distinct from already-open issue #1109 (Knowledge nav is a dead link) — this finding is about the item's continued *presence*, which #1109 does not address.
7. Operational: `deploy-demo-box.yml` fired three times in roughly 2.5 hours during this session and each one visibly disrupted live traffic (`net::ERR_ABORTED` on chat navigation, `signup-precheck` 500s) for several minutes while containers recreated. Not a demo defect, but a real risk: a deploy landing during an actual live demo would produce the same disruption.
